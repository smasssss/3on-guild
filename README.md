# 3ON 운영센터

공개 주소: https://smasssss.github.io/3on-guild/

GitHub Pages는 기존 `main` 브랜치의 루트 `index.html`을 게시합니다. 빌드나 외부 리소스 없이 단일 HTML로 실행됩니다. 성장추적 · 마차관리 · 운영이력 · 관리설정으로 구성됩니다.

2026-10-06 최종 승인 성장자료의 현재 길드원 91명과 관측값 3,534개를 유지합니다. 이전 공개본의 명단 제외 인원도 보관 이력에 추가하여 전체 관측값 3,849개를 보존합니다. 가나디고나니→키위의 관측값 20개와 VIP 1회, 용팝이/용퍕이 계정 분리를 유지합니다. VIP 기초값은 사용자 최종 재확인에 따라 기존 수정 HTML 그대로이며 999회 이상은 999회입니다.

## 운영자료 보존

- 저장 방식은 해당 주소를 연 브라우저의 `localStorage`, 기존 저장 키는 `3on_carriage_proto_v1`입니다. 배포와 페이지 열기는 저장값을 덮어쓰지 않습니다.
- PC·휴대폰·브라우저 간 자동 공유 또는 서버 DB는 없습니다. 관리설정에서 운영자료 JSON을 다운로드하고 다른 환경에서 기본값인 ‘병합 · 현재 기록 우선’으로 가져오세요. 로컬 HTML에서 공개 웹으로 옮길 때도 같은 절차가 필요합니다.
- 저장·수정·삭제·복구 전에 이전 원본을 자동 백업합니다. 자동 백업 역시 같은 브라우저에 저장되므로 외부 JSON 다운로드를 권장합니다. 손상된 자료와 다른 창의 동시 변경은 저장을 차단합니다.
- 병합은 동일 ID/날짜 충돌 시 기존 자료를 보존합니다. VIP 기초값은 합산하지 않으며 다른 기존 값은 자동으로 덮어쓰지 않습니다. 충돌은 확인용 파일로 내보냅니다.
- 주차는 월요일~일요일이며 새 주차가 시작되어도 기록을 삭제하지 않습니다. 수동 초기화에는 관리자 접근과 두 번의 확인이 필요합니다.
- 관리자 접근 방식은 기존 승인본의 클라이언트 잠금입니다. 서버 인증이나 공유 데이터 접근 제어를 제공하지 않습니다. 관리 비밀번호는 브라우저에 전달되는 코드에 포함됩니다.

## 업데이트와 복구

새 성장자료를 반영할 때 외부 `GROWTH`와 내부 `growthPayload`의 관측자료를 함께 갱신하고 안정된 내부 ID와 저장 키를 유지하세요. 저장된 운행의 당시 성장정보는 수정하지 않습니다. 화면은 최신 닉네임을 공통 사용합니다.

배포 전 원본 커밋: `96c3e3d4fc8a50bd0363fdf86b69f758233d0933`. Git 이력과 별도 Git bundle 백업으로 기존 웹을 복구할 수 있습니다. 실제 운영자료는 Git에 올리지 말고 관리자 브라우저에서 별도 백업하세요.

브라우저 뒤로가기는 내부 탭/VIP 창을 복귀하고 마지막 화면에서는 2초 안내 후 두 번째 입력을 브라우저 기본 뒤로가기로 처리합니다. 일반 브라우저 탭을 강제로 닫지 않습니다.
